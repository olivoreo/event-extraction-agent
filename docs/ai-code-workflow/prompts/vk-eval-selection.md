# Prompt: VK Eval Selection

Use this prompt to select a compact but representative evaluation sample from VK posts for an event extraction agent.

```text
Ты помогаешь собрать тестовую выборку для backend-агента извлечения мероприятий из VK-постов.

Вход:
- JSON со списком постов.
- Каждый пост содержит text/raw_text, source_name, source_url, published_at, external_id.

Задача:
Выбери репрезентативную выборку постов для ручной gold-разметки.

Критерии выбора:
- прямые анонсы будущих или актуальных мероприятий;
- напоминания о мероприятиях;
- конкурсы, голосования, прием заявок, регистрации и дедлайны;
- переносы и отмены;
- посты с несколькими датами или несколькими самостоятельными событиями;
- посты, где одно мероприятие повторяется в непоследовательные даты, например "9 и 11 мая в 18:00";
- посты с непрерывным диапазоном или последовательными днями, например "3-5 января" или "3, 4, 5 января";
- отчеты, фото-рекапы, итоги, поздравления победителей;
- новости, инструкции, вакансии и другие не-анонсы;
- дубли одного и того же события, включая более ранний и более поздний пост;
- неоднозначные случаи: нет названия, нет времени, относительные даты, неполная площадка.

Не выбирай однотипные посты только ради объема. Лучше меньше, но с покрытием разных ошибок.

Верни JSON:
{
  "selection_reason": "коротко опиши принцип отбора",
  "selected_posts": [
    {
      "selection_tags": ["direct_announcement", "date_with_time"],
      "selection_note": "почему этот пост важен для теста",
      "post": { ...исходный объект поста без изменений... }
    }
  ]
}
```
